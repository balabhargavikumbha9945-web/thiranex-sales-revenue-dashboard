# Sales & Revenue Analysis Dashboard

## Overview

This project is a **Sales & Revenue Analysis Dashboard** developed during the **Thiranex internship**. It analyzes sales, revenue, profit, customers, orders, products, and categories to identify useful business insights.

## Objectives

* Analyze overall sales and revenue performance
* Understand category-wise sales
* Identify top-performing products and customers
* Analyze monthly sales trends
* Understand profit distribution across customer segments
* Create interactive visualizations and filters

## Key Performance Indicators

* **Customers:** 116
* **Orders:** 171
* **Quantity:** 23K
* **Sales:** 2.25M
* **Profit:** 1.01M

## Technologies Used

* Python
* Pandas
* Matplotlib
* Plotly
* Google Colab

## Analysis Performed

The project includes:

1. **Sales by Category**
2. **Monthly Sales Trend**
3. **Top 5 Products**
4. **Top 5 Customers**
5. **Profit Percentage by Segment**
6. **Interactive Filters**

   * Category
   * Month

## Business Insights

* Technology is the largest sales category in the analyzed data.
* Consumer has the highest displayed profit percentage by segment.
* July has the highest displayed monthly sales.

## Output Files

The project generates CSV files containing the analyzed results for different aspects of the dashboard.

## Conclusion

This project demonstrates how Python-based data analysis and visualization can be used to understand sales performance, revenue trends, customer behavior, product performance, and profitability.
